# Instrucciones del proyecto Organizador Académico

## Objetivo

Desarrollar una aplicación para organizar las tareas escolares de un estudiante, agrupándolas por materia y fecha de entrega.

## Tecnologías

- Python 3.14.7
- Git para el control de versiones.
- GitHub para alojar y compartir el proyecto.
- OpenCode como asistente para el desarrollo.

## Funcionalidades previstas

1. Crear tareas con título, descripción, materia y fecha de entrega.
2. Mostrar todas las tareas registradas.
3. Filtrar las tareas por materia.
4. Marcar tareas como completadas.
5. Guardar las tareas para conservarlas al cerrar el programa.

## Buenas prácticas

- Escribir código claro, organizado y fácil de mantener.
- Usar nombres de variables y funciones descriptivos.
- Dividir el código en funciones cuando sea conveniente.
- Validar los datos que introduce el usuario.
- Explicar los cambios importantes antes de realizarlos.
- No añadir dependencias innecesarias.
- No modificar archivos ni ejecutar acciones destructivas sin autorización.
- No inventar archivos, funciones ni resultados: comprobar el estado real del proyecto.

## Reglas de trabajo con Git

- Crear commits pequeños que representen cambios relacionados.
- Usar mensajes de commit claros y descriptivos.
- No incluir contraseñas, tokens ni otros secretos en el repositorio.
- Revisar los cambios antes de registrarlos.
- No ejecutar `git push`, `git reset --hard` ni otros comandos que puedan alterar el historial remoto sin autorización explícita.

## Forma de trabajo

Antes de programar una funcionalidad, explicar brevemente el plan y los archivos que se modificarán. Después, realizar cambios pequeños y comprobar que funcionan. Si existe alguna duda sobre los requisitos, preguntar antes de asumir.
